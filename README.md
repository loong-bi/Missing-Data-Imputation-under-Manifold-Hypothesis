# Missing Data Imputation under the Manifold Hypothesis

This repository contains the source code for the experiments reported in the paper **“Missing Data Imputation under the Manifold Hypothesis.”**

* `imputation_method.py` contains the code for experiments on **simulated datasets**.
* `impute_method.py` contains the code for experiments on **real-world datasets**.

The code is functional and can be used to reproduce the experiments reported in the paper. However, it has not been optimized for operational efficiency or production use. For serious deployment or applications, users are encouraged to implement their own version based on the methodology described in the paper, with appropriate optimization, testing, and engineering considerations.
